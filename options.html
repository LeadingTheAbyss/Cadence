Usernames

GitHub tracking needs a Personal Access Token to read your commits, issues, pull requests, and PR reviews. Create a classic PAT at github.com/settings/tokens with the repo scope (or public_repo if you only ever work in public repositories). A token without this scope can't see activity in your private repos, it'll silently look like nothing happened, even if you're not actually done. The token is stored locally in this browser's extension storage only and never leaves your machine except to call GitHub's API.
